## هل تكمل باقي المعادلات الآن؟

**لا — الترتيب الأمثل:**

```
الشهر 1–2:   أنهِ P1 (E1+E2) وأرسلها ← أنت هنا الآن
الشهر 3–4:   انتظر رد المراجعين على P1
               + ابدأ تدريب E3+E4 بالتوازي
الشهر 5–6:   رد على مراجعي P1 + أرسل P2
الشهر 7–12:  E5+E7 → P3
```

**السبب:** إذا بدأت E3 الآن، ستشتت تركيزك وستصل P1 ناقصة. P1 هي البوابة لكل شيء بعدها.
